# CubicSplines

Ausführbare Python Programme:
* `splinewithpointsapp.py`: Zeichne einen eindimensionalen Spline durch einige frei bewegliche Stützpunkte.
* `splinewithpointsapp.py`: Zeichne einen eindimensionalen Spline durch Stützpunkte gegeben durch eine Funktion.
* `2dsplinesapp.py`: Zeichne einen zweidimensionalen Spline durch einige frei bewegliche Stützpunkte und lasse einen Punkt darauf "fahren".

Verwendung von KI: Ich habe ChatGPT verwendet, um schneller mit tkinter die Visualisierung erstellen zu können. Dabei hat ChatGPT keine längeren Code-Segmente geschrieben, sondern nur dabei geholfen, die passenden Klassen und Funktionen aus dem Modul zu finden. Für die Entwicklung der Klassen in `splineclasses.py` und `splineclassesnd.py` habe ich keine KI verwendet.
